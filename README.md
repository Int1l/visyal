# Black Launcher

Сборка (Windows): установить Rust (rustup.rs), затем
    cargo build --release
Файл: target/release/black-launcher.exe

Требуется: установленная версия в .minecraft (официальный лаунчер или Fabric installer), Java 17/21.
В настройках укажи ник, RAM, путь к Java (javaw или полный путь) и папку игры.
